# Как обновить пресеты в DeepSeek Harness

Пресеты — это инструкции и настройки для работы агента в DSH. Например, у тебя могут быть установлены Fable, Astra или другой пресет из проекта DSH PTC Presets.

## Что происходит по понедельникам

В **10:00 по Москве** GitHub Actions по расписанию проверяет исходный архив. Компьютер пользователя может быть выключен. Если нашлись подходящие изменения, сопровождающий проверяет их и публикует в DSH PTC Presets. Время публикации зависит от проверки. [Отчёты GitHub](https://github.com/Kotpes537/dsh-ptc-presets/actions/workflows/upstream.yml)

На своём компьютере запускай проверку сообщением в DSH в любое удобное время. Если ты включил компьютер позже, например в понедельник в 11:00 или во вторник, открой DSH и отправь то же сообщение. Агент проверит всё, что к этому моменту опубликовано. Если обновление выпустят после твоей проверки, оно будет доступно при следующем запросе.

## Что сделать в DSH

1. Открой новую сессию **DeepSeek Harness** на Windows.
2. Отправь в чат следующее сообщение.

> Проверь и подготовь обновление моих установленных модельных пресетов по инструкции https://github.com/Kotpes537/dsh-ptc-presets/blob/main/docs/UPDATE-FOR-USERS-RU.md. Выполни команды сам. Если обновление готово, скажи, когда выйти из DSH, и сохрани в чате путь к отчёту.

3. Если агент написал **«Обновление подготовлено»**, закончи работу в открытых сессиях и в течение 15 минут выбери в DSH **Приложение → Выход**. Windows сохранит копии прежних файлов, установит обновлённые промпты и снова откроет DSH. Если тебе нужно больше времени, запусти проверку ещё раз, когда будешь готов выйти.
4. После запуска вернись в тот же чат и напиши **«Проверь отчёт обновления. Что установилось и где резервная копия?»** Затем попробуй обновлённый пресет в новой сессии. Если DSH не открылся сам, открой его как обычно.

Если агент ответил **«Обновлений нет»**, можно продолжать работу. Если он обнаружил локальную редакцию, он укажет путь к файлу и пропустит его. Установщик обновляет опубликованные промпты для уже установленных пресетов. Новые пресеты можно добавить отдельно. [Инструкция по установке](../INSTALL-FOR-AI.md)

Обновление меняет инструкции агента. Подключённая API-модель управляется провайдером DSH.
