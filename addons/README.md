# Рабочие пресеты DSH

Рабочий пресет задаёт процесс под конкретную задачу. Его можно установить отдельно, используя уже подключённую в DSH модель.

| Пресет | Для чего | Установка |
| --- | --- | --- |
| Research Manager | Дизайн потребительских исследований, анализ и методическое ревью | [Инструкция для ИИ](research-manager/INSTALL-FOR-AI.md) |

Для экспериментов, CRM, стратегии и других задач есть также [готовые связки субагентов](../docs/agent-schemes.md). Каждую можно установить командой сборки с `--only --team <имя>`.

Отдельные модельные пресеты выбираются по ID в [каталоге](../presets/catalog.json). [Общая установка](../INSTALL-FOR-AI.md)
