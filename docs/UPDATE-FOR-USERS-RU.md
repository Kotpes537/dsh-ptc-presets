# Обновление модельных промптов из DeepSeek Harness

На Windows пользователь начинает проверку в чате DSH Desktop. Скрипт сравнивает файлы промптов активных пресетов с опубликованными контрольными суммами. Для установки он готовит файлы и запускает отдельный процесс Windows, а пользователь штатно выходит из DSH. Процесс сохраняет резервную копию, сверяет результат и открывает приложение. [Короткая инструкция для пользователя](КАК-ОБНОВИТЬ-ПРЕСЕТЫ.md)

Нужны Git, Python 3.10+ и доступ к терминалу, файлам профиля и GitHub. Источником служит опубликованный список промптов DSH PTC Presets. GitHub проверяет исходный архив по понедельникам в 10:00 по Москве. Сопровождающий оценивает изменения до публикации. Локальная проверка в DSH начинается по запросу пользователя и сверяет файлы с тем, что уже опубликовано на момент запуска. [Отчёты мониторинга](https://github.com/Kotpes537/dsh-ptc-presets/actions/workflows/upstream.yml)

## Команды для агента в DSH

1. Найди фактический профиль `profiles/desktop`. По умолчанию это `%USERPROFILE%\.dsh\profiles\desktop`. Если DSH использует свой `DSH_HOME`, укажи этот профиль через `--profile-dir`. Найди установленный Python, при необходимости используй `py -3`.
2. Получи копию опубликованной ветки `main` в новую папку. История Git нужна, чтобы сверять файлы с ранее опубликованными версиями. Выполни команды из корня этой копии. Если команда вернула ошибку, выясни причину перед следующим шагом.

```powershell
$checkout = Join-Path $env:TEMP ('dsh-ptc-update-' + [guid]::NewGuid().ToString('N'))
git clone --single-branch --branch main https://github.com/Kotpes537/dsh-ptc-presets.git $checkout
if ($LASTEXITCODE -ne 0) { throw 'Не удалось получить репозиторий' }
Set-Location -LiteralPath $checkout
python -B -X utf8 .\scripts\update_prompts.py check
if ($LASTEXITCODE -ne 0) { throw 'Проверка обновления не завершилась' }
```

3. Если доступное обновление найдено и пользователь попросил применить его, запусти подготовку. Для нестандартного профиля передай тот же `--profile-dir` в обе команды.

```powershell
python -B -X utf8 .\scripts\update_prompts.py queue
if ($LASTEXITCODE -ne 0) { throw 'Не удалось подготовить обновление' }
```

4. Если скрипт подтвердил готовность, укажи путь к `result.json` и попроси пользователя закончить работу в других сессиях и выбрать **Приложение → Выход**. Процесс ждёт полного выхода до 15 минут. Папка с копией репозитория нужна до окончания установки.
5. Когда пользователь после запуска DSH попросит проверить результат, прочитай `result.json` по пути из предыдущего сообщения. Статус `installed` означает, что хеши установленных промптов проверены. Поле `restart` сообщает результат запуска приложения. Покажи список изменённых файлов и путь к резервной копии. Проверь затронутый пресет в новой сессии и при доступной модели выполни короткий запрос. Статус `blocked` сопровождается причиной остановки.

Скрипт обновляет только тексты уже подключённых модельных промптов, которые совпали с прежней опубликованной версией. Локальную редакцию он показывает отдельно. Архивные тексты проверяются по SHA-256. Настройки DSH, допуски помощников и файлы рабочих пресетов сохраняются. Для новых модельных пресетов используется [выборочная установка](../INSTALL-FOR-AI.md).

Если после применения понадобится откат, возьми из отчёта путь к `backup` и список файлов в `updated`. Заверши задачи и выйди из DSH штатно. Сверь, что с момента обновления эти файлы не правились, и восстанови их из копии по тем же относительным путям в профиле. Затем открой DSH и проверь пресет.
