# Как обновить пресеты в DeepSeek Harness

Пресеты — это инструкции и настройки для работы агента в DSH. Например, у тебя могут быть установлены Fable, Astra или другой пресет из проекта DSH PTC Presets.

## Что сделать

1. Открой новую сессию **DeepSeek Harness** на Windows.
2. Отправь в чат следующее сообщение.

> Проверь и подготовь обновление моих модельных промптов по инструкции https://github.com/Kotpes537/dsh-ptc-presets/blob/main/docs/UPDATE-FOR-USERS-RU.md. Выполни команды сам. Если обновление готово, скажи, когда нужно выйти из DSH, и дай путь к отчёту.

3. Если агент написал **«Обновление подготовлено»**, закончи текущую работу и выбери **Приложение → Выход** в DSH. Установщик дождётся выхода, сохранит прежние файлы и снова откроет приложение. Открой новую сессию и попробуй свой пресет. Если DSH не открылся, запусти его вручную и попроси агента прочитать отчёт по указанному пути.
4. Если агент сообщил, что обновлений нет, продолжай работу. Если он указал на локальную редакцию файла, этот файл нужно рассматривать отдельно.

## Когда проверять

Проверяй обновления в любое удобное время. По понедельникам GitHub проверяет исходный архив. Сопровождающий проекта рассматривает изменения перед публикацией обновлённых промптов.

Обновление пресета меняет инструкции агента. Подключённая API-модель выбирается и обновляется через провайдера DSH.
