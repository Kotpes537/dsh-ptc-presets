# DSH PTC Presets

54 пресета для DeepSeek Harness Desktop. В комплекте адаптированные инструкции, архивные варианты Full, правила делегирования и навыки для продолжения длинных задач и проверки результата. Модель, провайдер и режим рассуждения выбираются отдельно в DSH. [Каталог пресетов](presets/catalog.json)

## Установка на Windows

Проверенная версия DSH Desktop — **0.2.2-rc.5**. Для сборки нужен Python 3.10 или новее, для установки — PowerShell 7. Запусти DSH хотя бы один раз, чтобы создать профиль.

```powershell
git clone https://github.com/Kotpes537/dsh-ptc-presets.git
Set-Location dsh-ptc-presets
python scripts/presets.py build
Expand-Archive .\dist\DSH-PTC-portable.zip -DestinationPath .\dist\portable -Force
```

Выйди из DSH через меню приложения. Затем проверь и запусти установку:

```powershell
.\dist\portable\Install-DSH-PTC.ps1 -WhatIf
.\dist\portable\Install-DSH-PTC.ps1
```

Скрипт добавляет пресеты в профиль `desktop`. Можно указать отдельный каталог через `-ProfileDir`. Если у профиля уже есть `cordis.patch.yml`, скрипт сохраняет его копию рядом. При конфликте локальной настройки или файла он останавливается и показывает путь. Для существующей установки сначала сравни декларации по ID. После установки открой новую сессию и проверь меню пресетов.

Для отката закрой DSH и убери блок `PORTABLE DSH PTC` из `cordis.patch.yml`. Если после установки профиль не редактировался, можно восстановить прежний файл из сохранённой копии.

## Как устроены пресеты

- **Адаптированные** используют инструменты DSH, общие правила длинных задач и короткие инструкции под модель.
- **Full** добавляют архивный текст из зафиксированного источника и слой совместимости DSH. В открытой сборке пресет **Astra** также использует закреплённый архив GPT-6.2 Astra. Отличие Astra от **GPT-6.2 Astra Full** сохраняется в обвязке DSH.
- **Ревью** ограничен статическим просмотром файлов рабочей области. Профиль подключён как допустимый отдельный пресет для субагента Workflow.

Делегирование ограничено числом одновременно работающих потомков главного агента. По умолчанию High допускает **2**, Max — **3**. Для Fable 5.2, Opus 5.5 и GPT-6.2 Astra Max допускает **4**. Для Grok 4.7, Gemini 4 Neon и Gemini 4 Hydrogen переданный адаптером `xhigh` использует потолок Max.

## Обновления источника

Отчёт сравнивает текущий архив с последним проверенным коммитом. В нём видны изменения используемых файлов, новые возможные источники, переименования и прочие правки. На GitHub отчёт доступен в **Actions → Upstream prompts → Summary**. Можно запустить его вручную. Запланированная проверка идёт ежедневно. [Отчёты GitHub Actions](https://github.com/Kotpes537/dsh-ptc-presets/actions/workflows/upstream.yml)

Для локальной проверки:

```powershell
python scripts/presets.py upstream
```

Для выпуска новой версии сначала проверь отчёт и файлы источника. Затем обнови конкретные записи в `presets/upstream.lock.json`, пересобери ZIP и проверь установку. Отдельное поле `reviewed_commit` отмечает, до какого коммита просмотрен архив. Запланированная проверка публикует отчёт и оставляет выбор версий сопровождающему.

Архивные тексты скачиваются только при сборке локального ZIP. Для каждого файла зафиксированы коммит, путь, диапазоны строк и SHA‑256. В репозитории лежат декларации, адаптированные инструкции и ссылки на источники. [Описание источников](presets/local-plugins/ptc-workflow/full-prompts/SOURCES.md) · [Файл фиксации источников](presets/upstream.lock.json)

## Проверки перед изменением

```powershell
python scripts/presets.py check
python -m unittest discover -s tests -v
python scripts/presets.py build
```

Проверки сверяют каталог с декларациями DSH, реконструкцию архивных текстов по контрольным суммам и обработку переименований в исходном Git. GitHub Actions дополнительно устанавливает результат в отдельный профиль Windows.
